# Gosintegrator site

Сайт [gosintegrator.ru](https://gosintegrator.ru): каталог, заявки и кабинет администратора. Next.js 16, React 19. Сервер находится в отдельном проекте `gosintegrator-api`.

## Требования

Node.js 24. Для работы каталога и кабинета нужен запущенный API.

## Запуск

Откройте корень проекта в IDE. Скопируйте `.env.example` в `.env.local`.

```sh
npm ci
npm run dev
```

Локальный адрес: http://127.0.0.1:3000.

```sh
npm run typecheck
npm run build
npm start
```

## Настройки

`API_URL` задаёт адрес API для серверного прокси `/api`. `SITE_URL` — адрес сайта, `NEXT_PUBLIC_DEMO_MODE` — отображение демонстрационного режима. После изменения публичных параметров пересоберите сайт.

При сборке Docker-образа передайте доступный из контейнера адрес API через `--build-arg API_URL=...`. Значение по умолчанию `http://api:8080` требует общей Docker-сети с сервером под именем `api`. После изменения адреса пересоберите образ.

`npm run test:e2e` запускает браузерные проверки с отдельной тестовой базой. Для них дополнительно нужны собранный `gosintegrator-api`, .NET SDK и переменная `INTEGRATOR_API_ROOT` с путём к его корню. Основная сборка сайта от этого пути не зависит.
